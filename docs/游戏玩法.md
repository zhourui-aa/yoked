# 桌游玩法

## 如何开始游戏

1. 说"桌游模式"进入大厅
2. 输入"游戏名 人数"选择游戏，例如：剧本杀 6、狼人杀 8
3. 输入你的代号，例如：代号 周瑞
4. 输入"加入 昵称"为他人生成专属二维码，例如：加入 张三
5. 其他人扫码后自动绑定，人齐自动开始

## 剧本杀

### 游戏简介
4到9人推理游戏。AI主持人当场生成案件，每人有隐藏身份和秘密。通过讨论和搜证找出真凶。

### 游戏流程
1. 开局：AI宣布案件背景，私发角色卡给每位玩家
2. 调查阶段：玩家自由讨论，说"我要搜证"获取线索（每人3次）
3. 投票阶段：有玩家发起指认后，所有人投票选出凶手
4. 揭示真相：AI公布真凶、动机、手法，给每位玩家评分

### 搜证
说"我要搜证"或"调查线索"，AI会根据你的角色给出专属线索。每人最多3次。

### 指认和投票
说"我怀疑张三"、"指认李四"或"凶手是王五"发起指认。进入投票阶段后，每位玩家说出怀疑的凶手名字。所有人投票完毕后AI揭晓真相。

## 狼人杀

### 游戏简介
6到12人推理游戏。包含狼人、村民、预言家、女巫、猎人、守卫等角色。分为黑夜和白天两个阶段交替进行。

### 游戏流程
1. 开局：AI私发身份给每位玩家
2. 黑夜阶段：守卫守护→狼人讨论杀人→女巫用药/毒→预言家查验
3. 白天阶段：公布死者→自由讨论→投票放逐→公布身份
4. 循环直到狼人全部出局（好人胜）或狼人数>=好人数（狼人胜）

### 夜晚行动
夜晚阶段各角色按顺序行动，AI会私聊询问每个角色的决策。守卫不能连续两晚守护同一人，女巫解药和毒药各只能用一次。

### 白天讨论和投票
白天讨论阶段所有人的发言会广播给全体存活玩家。投票时每人一票，票多者被放逐。被放逐的猎人可以开枪带走一人。
